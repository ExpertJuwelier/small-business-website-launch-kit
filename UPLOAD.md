# Upload in five minutes

1. Download and unzip `website-launch-kit.zip`.
2. On GitHub, create a new **public** repository called `small-business-website-launch-kit`.
3. Select **Add file → Upload files**. Drag in `index.html`, `styles.css`, `app.js`, `README.md` and `LICENSE` from the unzipped folder. Upload the files themselves, **not the ZIP** and not the containing folder. Commit changes.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, set `main` and `/ (root)`, and save.
5. Open the published URL shown by GitHub Pages. Test the checklist, brief download and link. Add your Pages URL to the README.

If GitHub shows no Pages option, check that the repository is public and that you are viewing that repository's settings. Pages deployment can take a few minutes.
